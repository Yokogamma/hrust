# Hrust House — мокап лендингу

Тестовий мокап посадкової сторінки для **Hrust House** — три будиночки для відпочинку
за 15 хвилин від Чернівців (с. Валя Кузьміна).

Контент і фотографії зібрані з публічного акаунта [@hrust_house](https://www.instagram.com/hrust_house/)
і належать власникам комплексу. Сторінка закрита від індексації (`noindex` + `robots.txt`).

## Файли

| Файл | Що це |
|---|---|
| `index.html` | Уся сторінка — розмітка, стилі й скрипти в одному файлі. Адаптив: десктоп і мобільна версія. |
| `preview.html` | Десктоп (1280) і телефон (390) поруч — для показу клієнту без зміни розміру вікна. |
| `img/photo/` | Кадровані фото, що використовуються на сторінці. |
| `img/_source/` | Оригінали з Instagram, з яких зроблені кадри. |

## Що вміє сторінка

- Перемикач будиночків **Blue / Grey / Green** — змінює фото й акцентний колір усієї сторінки, вибір переноситься у форму бронювання.
- Календар на два місяці з позначенням зайнятості, вибором діапазону дат і синхронізацією зі швидким вибором у герої.
- Живий розрахунок вартості за реальними правилами комплексу.
- Галерея з лайтбоксом (стрілки, Esc), на мобільному — горизонтальна стрічка зі snap-скролом.
- Мапа OpenStreetMap без API-ключа, липке меню, мобільна панель бронювання.

Ніч рахується за днем заїзду. Знижки **не сумуються** — застосовується більша.

## Що потребує підтвердження клієнта

- Телефон — стоїть заглушка `+380 __ ___ __ __`.
- Меню та вартість сніданків.
- Повний перелік наповнення будиночків (у списку лише те, що видно на фото й у постах).
- Вартість оренди шатра 2 700 ₴ — у вихідному зображенні цифру було обрізано.
- Чи рахується «+500 ₴ за додаткового гостя» за добу (прийнято так) чи за весь заїзд.

## Обмеження мокапу

- Форма бронювання **нікуди не відправляється** — показує екран підтвердження. Бекенд (Telegram-бот, пошта, CRM) не підключений.
- Зайнятість у календарі — **демонстраційна**, генерується детерміновано. Зайняті дати позначені штрихуванням, але залишаються клікабельними: заявку можна надіслати, з'являється попередження.
- Точні координати на мапі не вказані — комплекс надсилає їх гостю після підтвердження бронювання.
